# My-Portfolio

A personal portfolio frontend application developed using React.js and Vite.

This portfolio showcases my personal information, technical skills, education, projects, certifications, and achievements. It serves as a digital resume.

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Lucide React

## Features

- Home
- About Me
- Technical Skills
- Projects
- Education
- Certifications
- Achievements
- Contact

## Installation and Setup

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```
